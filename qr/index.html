Les QR codes du livre

Vingt codes, un par emplacement du livre. Chacun mène à l'adresse portant son numéro.

Un code ne connaît pas le titre de l'enregistrement, seulement son numéro : c'est la page qui porte le contenu. Attribuer un enregistrement à un emplacement ne change donc rien au code déjà imprimé — et si l'hébergement déménage un jour, ces codes resteront valables.

Avant d'imprimer

  • 2,5 cm de côté au minimum, 3 cm de préférence. En dessous, les modules deviennent trop fins pour un téléphone tenu à bout de bras.
  • Noir sur blanc, sans logo au centre, sans fond de couleur. Le cadre blanc autour du code fait partie du code : ne pas le rogner.
  • Utiliser les fichiers .svg : ils restent nets à n'importe quelle taille. Les .png ne servent qu'aux logiciels qui refusent le vectoriel.
  • Scanner une épreuve papier avant de lancer le tirage — pas l'écran. C'est le seul test qui compte.
